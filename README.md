# switchback

[![tests](https://github.com/systemshocked88/switchback/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/systemshocked88/switchback/actions/workflows/tests.yml)

YouTube на телевизоре, Discord, Telegram, Instagram, ChatGPT и Claude — на всех устройствах дома, без VPN на каждом
из них. Обход блокировок ставится один раз на домашний роутер: zapret, DNS по сервисам и VPN для отдельных сервисов.

**[⬇ Скачать switchback.exe](https://github.com/systemshocked88/switchback/releases/latest/download/switchback.exe)**
(программа для Windows, последняя версия) ·
[инструкция](https://github.com/systemshocked88/switchback/releases/latest/download/guide.html) ·
[все версии](https://github.com/systemshocked88/switchback/releases)

Регистрироваться на GitHub не нужно: файл скачивается сразу.

## Как поставить — три шага

1. **Скачайте** `switchback.exe` по ссылке выше. Если Windows покажет синее окно «Система Windows защитила ваш
   компьютер» — нажмите «Подробнее» → «Выполнить в любом случае» (программа не подписана платным сертификатом).
2. **Запустите дома**, с компьютера, подключённого к вашему роутеру. Программа сама определит роутер и скажет,
   подходит ли он. Подходят Keenetic/Netcraze с USB-портом и роутеры с OpenWrt.
3. **Нажмите «Установить»** — пункт «YouTube и Discord на всех устройствах» уже выбран, настраивать ничего не
   нужно. Остальное (Telegram, ChatGPT, уведомления) добавляется там же, по желанию. До этого настройки роутера
   не меняются.

Нужно только на одном компьютере? Тогда проще поставить обход прямо на него (например, zapret для Windows).
switchback — когда должно работать у всех дома: на телевизоре, приставке, телефонах.

## Что даёт каждая часть

Части независимы: можно поставить одну, несколько или все сразу («Полный набор»).

| Что ставите | Что заработает | Что для этого нужно |
|---|---|---|
| **zapret** | YouTube (и на телевизоре, и на приставке), Discord, Instagram | только роутер; бесплатно |
| **DNS** | ChatGPT и Claude перестают писать «недоступно в вашей стране» | только роутер; бесплатно |
| **VPN для отдельных сервисов** | Telegram; по желанию Instagram, WhatsApp, Facebook. Остальной интернет идёт как раньше | файл WireGuard (`.conf`) от любого VPN-сервиса, обычно платного |
| **Сторож и бот** | сообщение, если что-то сломалось; команды боту «что с роутером» | свой бот в Telegram (создаётся за минуту) или приложение ntfy |
| **Автосмена туннеля** | Telegram не пропадает, когда один VPN-сервер перестал работать | два файла WireGuard или больше |
| **Серверы видео через VPN** (включается сама, когда есть VPN) | YouTube не зависает, когда провайдер глушит отдельные серверы видео: роутер сам находит такие (сервер должен не ответить напрямую 3 раза подряд) и отправляет в туннель только их; если сервер не отвечает и через туннель, роутер сам его оттуда убирает | файл WireGuard |

- **Нужен только YouTube на телевизоре** — начните с первой строки: ничего покупать не надо. Если видео грузится
  через раз — значит, провайдер глушит часть серверов видео целиком, и zapret тут не помогает: добавьте
  VPN-файл, дальше роутер справится сам. Так бывает не у всех провайдеров.
- **Честно про YouTube на телевизоре.** У части провайдеров (замечено в ноябре 2026) серверы видео
  глушатся один за другим, и видео на телевизоре встаёт каждые несколько минут даже с VPN-файлом. Тогда помогает
  одно: пустить Google и YouTube этого телевизора через VPN целиком — командой
  `sh install.sh sites tv add АДРЕС-ТЕЛЕВИЗОРА tv` (подробнее ниже, в списке команд). Бесплатно, одним zapret, YouTube на телевизоре у такого провайдера не заработает; скорость видео будет
  равна скорости VPN на роутере.
- **Не понравилось** — кнопка «Откатить всё» возвращает роутер как был.

Название: *switchback* по-английски — «серпантин», дорога в обход.

Установщик и пошаговая инструкция, как настроить роутер (Keenetic/Netcraze, OpenWrt; дальше Asus и MikroTik) так, чтобы **все устройства дома** (телефоны, телевизор,
приставки) без отдельных программ открывали YouTube, Discord, Instagram, Telegram, ChatGPT и Claude.

Собрано по опыту настройки одного домашнего роутера. Ничего личного здесь нет: адреса, ключи и пароли заменены на
`<вот такие>` заглушки.

> Материал технико-образовательный: как устроены блокировки и почему ломаются те или иные сервисы. Что можно
> делать у вас, решайте сами.

> **Просто поставить, без подробностей:** [простая инструкция](docs/guide.md) — для Keenetic/Netcraze и для роутеров,
> на которые можно поставить OpenWrt (как проверить и прошить). Её же HTML-версию [docs/guide.html](docs/guide.html)
> удобно отправить вместе с программой `switchback.exe`.

Программа для Windows `switchback.exe` и инструкция к ней — на странице **Releases** этого репозитория (справа на
странице проекта). Исходный код для этого скачивать не нужно.

  ссылкой на эту страницу. Если GitHub не отвечает — спрашивает запасную копию на Codeberg и открывает её страницу.
  Сама ничего не скачивает и не обновляет.
- Windows может предупредить о «неизвестном издателе»: программа не подписана платным сертификатом.

**Запасной адрес:** <https://codeberg.org/systemshocked/switchback> (запасная копия кода, обновляется с каждым
выпуском; готового файла программы там нет — только исходный код). Сообщения об ошибках — только на GitHub.

**Как не скачать подделку.** Копии таких программ с вирусами внутри — известная беда. Настоящие адреса только два:
`github.com/systemshocked88/switchback` и `codeberg.org/systemshocked/switchback`. Всё остальное — сайты, каналы,
архивы «с исправлениями», файлы в чатах — не наше. Проверить скачанный файл: на странице выпуска лежит `SHA256.txt`;
в папке с файлом откройте PowerShell и выполните `Get-FileHash switchback.exe` — число должно совпасть с числом
из `SHA256.txt` (большие или маленькие буквы не важны). Не совпало — не запускайте.

Распространяется по лицензии [MIT](LICENSE): бесплатно, без гарантий. Перед изменениями установщик сохраняет снимок
настроек роутера и умеет всё вернуть (`uninstall`), но роутер и сеть — ваши, и решение ставить — тоже ваше.

## Быстрая установка (установщик)

### Какие роутеры поддерживаются

Прошивку установщик определяет сам.

| Прошивка | Роутеры | Статус |
|---|---|---|
| **KeeneticOS** | Keenetic и Netcraze (с 2025 года Keenetic в России продаётся как Netcraze — та же прошивка) с USB-портом | ✅ анализ и установка |
| **OpenWrt** (opkg до 24.10 и apk с 25.x) | Xiaomi AX3000T, Cudy, TP-Link, GL.iNet и др. **после перепрошивки на OpenWrt**; iStoreOS, x-wrt | ✅ анализ и установка *(проверено на имитации, на живом роутере ещё нет)* |
| Asuswrt-Merlin | Asus | ⏳ запланировано |
| MikroTik RouterOS 7 | ARM64 / x86 | ⏳ запланировано |
| Заводские прошивки TP-Link, Xiaomi, Huawei… | — | ❌ сначала перепрошить на OpenWrt |

### Порядок

Подготовка:
- **Keenetic/Netcraze:** поставьте Entware ([шаг 1](docs/01-entware.md)); для Telegram импортируйте WireGuard
  ([шаг 4.2](docs/04-wireguard-telegram.md#42-импорт)).
- **OpenWrt:** Entware не нужен. Для Telegram добавьте WireGuard: Network → Interfaces → Add new interface →
  WireGuard VPN, в пире `Allowed IPs = 0.0.0.0/0` и **выключите** `Route Allowed IPs`, интерфейс — в зону `wan`.

Затем по SSH (`ssh root@192.168.1.1`):

**1. Скачать проект** (нужна вся папка, не один файл; на OpenWrt вместо `/opt/tmp` — `/tmp`):
```
cd /opt/tmp && curl -fsSL https://github.com/<АВТОР>/switchback/archive/refs/heads/main.tar.gz | tar xz && cd switchback-main
```
Если GitHub недоступен — то же с запасной копии (папка называется `switchback`; архив может готовиться до минуты):
```
cd /opt/tmp && curl -fsSL https://codeberg.org/systemshocked/switchback/archive/main.tar.gz | tar xz && cd switchback
```
**2. Анализ роутера** — ничего не меняет, говорит, подходит ли роутер и что может помешать:
```
sh install.sh doctor
```
**3. Пробный прогон** — показывает, что будет сделано, ничего не меняя:
```
sh install.sh --dry-run
```
**4. Установка:**
```
sh install.sh
```

### Что делает установщик

1. **Анализ** роутера (память, место, модули, конфликты, VPN «на всё», IPv6, доступ к репозиторию) и вердикт:
   «готово», «можно с оговорками» или «не рекомендую».
2. **Снимок всех настроек** до любых изменений, и подсказка, как из него восстановиться.
3. Установка выбранного **профиля**:

| Профиль | Что ставится | `--profile` |
|---|---|---|
| Полный (рекомендуется) | zapret + DNS + Telegram и Instagram через VPN + сторож и бэкап + автосмена туннеля | `full` |
| Только zapret | YouTube, Discord, Instagram | `zapret` |
| Только DNS | ChatGPT, Claude | `dns` |
| Только VPN | Telegram через WireGuard | `vpn` |
| Свой выбор | модули галочками | `custom` |

4. **Проверка после установки:** открываются ли сервисы.

По ходу он спросит: через какое VPN-подключение пускать Telegram и токен бота (не отображается при вводе), а также:

| | Keenetic / Netcraze | OpenWrt |
|---|---|---|
| DNS для ChatGPT/Claude | IP и имя (SNI) **DoT**-сервера сервиса | адрес **DoH** (`https://…/dns-query`); ставится `https-dns-proxy` |
| ПК со своим обходом | имя политики доступа для исключения | исключение пока не поддерживается — выключите обход на ПК |
| Ускорение | не трогается | предложит выключить flow offloading (иначе zapret не работает) |
| Бэкап | `show running-config` + папка Entware | `sysupgrade -b` (то же, что «Backup» в веб-интерфейсе) |

В терминале установщик цветной: шаги с номерами `[2/5]`, значки ✓ · ! ✗ и итоговая сводка. Если вывод
сохраняется в файл или копируется, цвета отключаются сами; вручную — параметр `--plain`.

**Без вопросов:** все ответы можно заранее записать в файл и запустить
`sh install.sh --answers answers.txt` — установщик ничего не спросит. Ключи и пример:
[docs/answers.md](docs/answers.md). Так же работает и будущая программа для Windows.

### Безопасность установки
- **Сбой посреди установки** (ошибка, пропал интернет, Ctrl+C) — изменения этого запуска откатываются сами.
- **Повторный запуск безопасен:** уже сделанное пропускается.
- **После обновления прошивки** запустите `sh install.sh doctor`. На OpenWrt обновление удаляет пакеты, а
  настройки и файлы switchback сохраняются: их установщик вносит в `/etc/sysupgrade.conf`. Анализ покажет,
  каких пакетов нет, а повторная установка их доставит. На Keenetic Entware на флешке обновление не трогает.
- **Убрать всё:** `sh install.sh uninstall` (есть `--dry-run`). Ручные настройки не трогаются.
- **Что установлено и работает ли:** `sh install.sh status` (ничего не меняет).
- **Отчёт для диагностики:** `sh install.sh report` — состояние роутера и нужные части настроек; пароли, ключи, токены
  и MAC-адреса вырезаны, а если в отчёте осталось хоть что-то похожее на секрет, он не выдаётся. Можно показывать тому,
  кто помогает разобраться. Копия на роутере: `/opt/var/switchback-report.txt` (OpenWrt: `/var/...`).
- **Автосмена туннеля (Keenetic и OpenWrt):** модуль `failover` — если основной WireGuard перестал пропускать трафик, маршруты
  сами переезжают на первый работающий запасной (настройки `switchback/failover.conf`, журнал `wg-failover/log`).
- **Быстрый узел Claude и запрет QUIC (Keenetic и OpenWrt):** модуль `nodes` — если DNS-сервис для Claude отдаёт
  несколько узлов, запрещает к ним QUIC, закрепляет Claude за самым быстрым и раз в минуту проверяет его; мёртвый или
  медленный узел меняется на более быстрый (только на узел с включённым правилом QUIC).
- **Резерв для нейросетей (Keenetic и OpenWrt):** если Claude или ChatGPT перестали открываться, роутер сам переходит
  на другой путь — DNS-сервис → Zapret DNS → запасные прокси → VPN через активный туннель (каждый путь сначала
  проверяется) — и сразу пишет в бот и ntfy. Вручную: `sh install.sh ai status`, `ai via vpn` (держится сутки),
  `ai next`, `ai auto`; в боте — `/ai` с кнопками «Claude через VPN», «Следующий путь», «Авто», «Статус». Включить —
  `ai on` или галочка «Резерв для нейросетей» в программе, выключить — `ai off`.
- **WireGuard из файла:** `sh install.sh wg-import --conf vpn.conf` создаёт подключение только для выбранных
  адресов; ключи не попадают ни на экран, ни в журналы. `--standby` — добавить выключенным (запасной для автосмены).
- **Много серверов сразу (Keenetic):** пришлите боту архивы .zip или файлы .conf с серверами WireGuard и нажмите
  «Проверить и добавить» (или `sh install.sh wg-batch --conf ПАПКА`). Роутер проверяет каждый сервер настоящим трафиком,
  берёт по очереди из каждого архива, пропускает повторы и оставляет до 6 рабочих запасными туннелями автосмены;
  остальные сразу удаляет. Присланные файлы с ключами стираются после проверки.
- **Свои сайты:** `sh install.sh sites add example.com --via zapret` (тормозит, как YouTube), `--via dns` (пишет «недоступно в
  вашей стране», как ChatGPT; тот же DNS-сервер), `--via vpn` (не открывается совсем, как Telegram; адреса сайта идут через
  туннель Telegram и обновляются сами каждые 5 минут). Список — `sites`, убрать — `sites del example.com`.
- **YouTube на телевизоре встаёт каждые несколько минут:** `sh install.sh sites tv add 192.168.1.50 tv` (адрес устройства
  в домашней сети) — все обращения этого устройства к Google и YouTube пойдут через VPN-туннель, остальное на нём и
  все другие устройства — как раньше. Нужно, когда провайдер глушит серверы видео один за другим: по одному их не
  переловить. Скорость YouTube на устройстве — скорость туннеля. Убрать — `sites tv del tv`.
- **Запасной канал уведомлений — ntfy:** Telegram идёт через VPN, и когда туннель падает, сообщение о поломке туда не
  доходит. Тогда сторож, бэкап и автосмены шлют его push-уведомлением в приложение ntfy (оно работает напрямую). Канал —
  длинное случайное имя; можно и совсем без бота, только ntfy.
- **Самолечение:** сторож сам перезапускает упавший zapret. В 04:30, если свободной памяти меньше 20% (на слабых
  роутерах она понемногу утекает), роутер перезагружается, пока все спят, — не чаще раза в сутки. После любой
  перезагрузки приходит сообщение: почему (ночная или без плана — например, пропадало питание) и работает ли zapret;
  в субботней сводке — список перезагрузок. Отключить ночную перезагрузку — строка `NIGHT_REBOOT=0` в `bot.conf`.
- **Команды боту:** если настроен сторож, бот отвечает в своём чате на `/status`, `/check` (открываются ли сайты),
  `/report` (отчёт файлом) и `/sites` — только вам, остальным молчит. Главные команды — кнопками меню внизу чата;
  действия (сменить туннель, закрепить узел Claude, добавить сайт) бот переспрашивает с кнопками «Да» и «Нет».
  Кнопка **«Что-то не работает»** проверяет по цепочке интернет, zapret, YouTube, туннель, Claude, ChatGPT и свои сайты
  и отвечает простыми словами, что делать, с кнопкой исправления. Можно прислать боту просто адрес сайта: он
  проверит, открывается ли тот с роутера, и предложит пустить его в обход. «Телевизор» — устройства, у которых
  YouTube идёт через VPN (убрать и вернуть кнопкой), «Подобрать zapret» — подбор прямо из Telegram, «Claude» (`/ai`) —
  каким путём идут Claude и ChatGPT и переключение вручную.
- **Сообщения роутера — по-русски и с подсказкой**, что делать (или что делать ничего не нужно).
- **Запас туннелей:** каждый день в 05:00 автосмена по очереди проверяет запасные туннели (каждый включается на
  несколько секунд и снова выключается). Когда отвечает один или ни одного — сообщение: пора добавить новый
  конфиг WireGuard, пока основной жив.
- **Подбор настроек zapret:** `sh install.sh tune` — если YouTube снова тормозит: пробует 12 способов обхода, мерит с роутера
  и ставит три лучших (4–11 минут; сайты в это время могут подтормаживать). Последним всегда добавляет запасной способ
  с www.google.com и отдельно проверяет адрес, через который ходит приложение YouTube. Не лучше, чем было, — ничего не
  меняет; вернуть как было — `tune --undo`. То же — кнопкой «Подобрать zapret» в боте.
- **Отдельные способы для серверов видео YouTube:** при установке у серверов googlevideo.com свой набор способов из
  7 штук «по кругу» — у каждого сервера видео свой: если способ перестал работать для сервера, zapret сам берёт следующий. Включить на уже настроенном роутере —
  `sh install.sh tune video on`, выключить — `tune video off`. Свои настройки в `NFQWS_ARGS_CUSTOM` не трогаются.
- **Обновление:** `sh install.sh update` из новой версии — заменяет скрипты switchback на роутере новыми, настройки не трогает.
- **Списки адресов и способов** лежат в папке `lists/`. Версия списков на роутере — `sh install.sh lists`. Обновить
  их отдельно от программы — кнопка «Обновить списки» на экране статуса: свежие списки с GitHub (или с запасной копии
  на Codeberg) ставятся только с верной подписью; стало хуже — роутер сам возвращает прежние, вручную — кнопка
  «Вернуть прежние» или `sh install.sh lists restore`.
- **Панель на роутере** (по умолчанию выключена): `sh install.sh panel on` — страница для телефона или компьютера
  дома. На ней видно, работают ли YouTube, Telegram, Instagram, ChatGPT и Claude, свои сайты и каким путём идут; там же
  кнопка «Переключить на следующий» туннель и проверка «Не открывается сайт?». Вход — по ссылке, которую покажет
  установщик (`panel link`; новая ссылка — `panel token`), пароль роутера не нужен. Открывается только из домашней сети.
  Выключить — `panel off`. Устройство и защита: [docs/panel-plan.md](docs/panel-plan.md).
- **Почему не открывается сайт:** `sh install.sh sites doctor example.com` — по шагам: интернет, открывается ли сейчас,
  адрес сайта, туннель; и что поможет. То же — ссылкой или адресом в боте и в панели.
- **Если всё равно сломалось:** [docs/recovery.md](docs/recovery.md) — от «откатить командой» до сброса роутера.
- Журнал: `/opt/var/log/switchback.log`, снимки: `/opt/etc/switchback/backups/`.

**Как части работают вместе и по отдельности, что за что отвечает:** [docs/how-it-works.md](docs/how-it-works.md).

## Как сообщить о проблеме

1. **Сначала посмотрите сами:** `sh install.sh status` (или `/status` и `/check` у бота) покажет, что именно не
   работает. Если сломалось после установки — [docs/recovery.md](docs/recovery.md).
2. **Сделайте отчёт** — любым из способов:
   - боту: `/report` (пришлёт файл);
   - в программе: экран «Статус» → «Отчёт для диагностики»;
   - на роутере: `sh install.sh report`.

   Пароли, ключи, токены и MAC-адреса из отчёта вырезаны. Это обычный текст: перед отправкой его можно прочитать.
3. **[Выберите форму](https://github.com/systemshocked88/switchback/issues/new/choose)** (нужна бесплатная
   учётная запись GitHub): «Не открывается сайт / YouTube», «Не ставится / ошибка при установке» или
   «Telegram / туннели WireGuard». Заполните поля и приложите отчёт. Всё заработало — расскажите об этом
   формой «Проверено на моём роутере»: она пополнит список проверенных роутеров.

**Не выкладывайте** пароли, токен бота, файлы WireGuard (`.conf`) и полную настройку роутера (`running-config`):
Issues видны всем.

Ниже — то же самое по шагам, если хочется понимать, что происходит, или сделать вручную.

## Что нужно

- Роутер **Keenetic** с USB-портом. Чем больше памяти, тем лучше. Всё работает даже на старом Extra с 128 МБ.
- **USB-флешка** от 1 ГБ (будет отформатирована).
- Для Telegram: **конфиг WireGuard** (файл `.conf`) от любого VPN-сервиса, который его выдаёт.
- Компьютер для SSH (в Windows 10/11 команда `ssh` уже есть в PowerShell).
- Час-два времени и **бэкап настроек роутера** перед началом.

## Главные уроки (если читать только это)

1. **Не запускайте два обхода на один и тот же трафик.** Если на ПК уже работает свой zapret или GoodbyeDPI,
   исключите этот ПК из zapret на роутере (см. [03-zapret.md](docs/03-zapret.md#исключить-пк)). Иначе ломается всё.
2. **zapret в режиме `list`, а не `auto`.** Auto сам решает, что «обходить», и иногда ломает работающие сайты.
3. **DNS-прокси могут «протекать» через HTTPS-записи.** iPhone берёт оттуда настоящий адрес сайта и идёт мимо
   прокси. Проверяйте ([02-dns.md](docs/02-dns.md#проверка-на-утечку)).
4. **Приложения ходят по QUIC (UDP 443).** Если сайт в браузере работает, а приложение через раз, закрепите адрес
   и запретите UDP 443 к нему ([02-dns.md](docs/02-dns.md#приложение-работает-через-раз)).
5. **Один DoT-сервер на весь дом опасен.** Если он упадёт, пропадёт DNS у всех. Привязывайте DoT к доменам.
