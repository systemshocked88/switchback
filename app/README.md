# switchback.exe — программа для Windows

Своё окно (Go + Wails, внутри обычный HTML). Подключается к роутеру по SSH, копирует туда установщик
и запускает его. Пароль нужен только для входа и нигде не сохраняется.

## Что умеет сейчас

0. **Какой у вас роутер** — программа сама спрашивает роутер в домашней сети (UPnP, без пароля), какой он модели: Keenetic и OpenWrt
   выбираются сами, для заводской прошивки модель подставляется в проверку «подойдёт ли OpenWrt»; заодно подставляется адрес роутера.
   **Что нужно заранее** (при первом запуске): выбор прошивки и список условий с галочками и подсказкой
   «как сделать». Для Keenetic: USB-порт, флешка ext4, компоненты, Entware, сменённый пароль root. Для OpenWrt:
   пароль, SSH, интернет. Отдельно — что нужно только для Telegram, DNS и бота. Для другой прошивки —
   объяснение, что сначала нужен OpenWrt. Список совпадает с `docs/01-entware.md` и README: меняйте их вместе.
   Снова открыть его можно ссылкой на экране подключения.
1. **Подключение:** адрес, порт SSH, пользователь, пароль. При первом подключении программа запоминает
   ключ роутера (`%APPDATA%\switchback\known_hosts`). Если ключ потом изменится, она откажется
   подключаться и предложит «Забыть ключ»: так бывает после сброса роутера, но может быть и подменой.
2. **Анализ:** распаковывает установщик в `/tmp/switchback` на роутере (это память роутера, после
   перезагрузки папка исчезнет) и запускает `install.sh doctor --progress`. Анализ ничего не меняет.
3. **Что установить:** полный набор, отдельные части или выбор вручную.
4. **Настройки:** только для выбранных модулей. Исключение ПК (Keenetic) или ускорение (OpenWrt); DNS для ChatGPT и Claude
   (Keenetic: IP и имя DoT-сервера, OpenWrt: адрес DoH); подключение WireGuard из найденных анализом; токен бота
   с кнопкой «Проверить» (проверка с ПК через api.telegram.org, номер чата берётся из `getUpdates`).
5. **Установка:** «Пробный прогон» или «Установить» (подтверждение повторным нажатием). Ответы уходят на роутер в
   файл с доступом только для root, установщик удаляет его сразу после чтения. Установщик работает **отдельно от
   SSH-сессии**: если связь пропадёт, он доделает или откатит всё сам (журнал: `/tmp/switchback/run.log`).
   Шаги, проверки, итог; «Сохранить снимок настроек на компьютер» скачивает папку снимка как `.tar.gz`.

6. **Автосмена туннеля** (Keenetic, модуль в полном наборе): поле «туннели по порядку», по умолчанию — сначала тот,
   через который идёт Telegram, потом живые.
7. **WireGuard из файла** (на экране настроек): выбрать .conf → он уходит только на роутер, `install.sh wg-import`
   создаёт подключение (только для адресов Telegram), копия удаляется. Команды Keenetic — те же, что в проверенном wg-import.sh.
8. **Статус и откат:** `install.sh status` по группам; «Откатить всё» (`uninstall`, по желанию с пакетами; неактивна, если откатывать нечего),
   подтверждение повторным нажатием, запуск отдельно от SSH-сессии.
9. **Отчёт для диагностики** (экран «Статус»): `install.sh report` на роутере — секреты вырезаны и проверены там же —
   и сохранение текстом на ПК.
9d. **Поставить Entware** («Что нужно заранее» → Keenetic): через веб-интерфейс роутера (`KeeneticCheck`, `InstallEntware`):
   компоненты, флешка ext4, `opkg disk`, ожидание, новый пароль root. «Добавить запасной туннель» — WireGuard выключенным.
9c. **Готовые DNS-сервисы** (настройки, DNS для ChatGPT и Claude): список проверенных (`DNSPresets`: Keenetic — DoT GeoHide,
   Bezmezhau; OpenWrt — DoH Zapret DNS) и «Свой вариант»; «Проверить, работает ли» (`CheckDNS`) спрашивает сервис с ПК и
   открывает сайт через выданный адрес. Подсказка, где взять конфиг WireGuard (например, ZapretKVN), и проверка туннеля трафиком.
9b. **Запасной канал ntfy** (настройки, «Сторож и бэкап»): имя канала программа придумывает сама (`NewNtfyChannel`), ссылки на
   приложение, «отправить проверочное уведомление» с ПК (`TestNtfy`); канал, уже стоящий на роутере (событие `ntfy`), не меняется.
9a. **Подсказки по прошивке** (экран анализа, событие `fw`): OpenWrt старше последней стабильной — как обновиться, ссылка на выбор
   прошивки для этой модели (board_name → id); KeeneticOS 3.x — что даёт 4.x. Instagram/Facebook/WhatsApp через VPN — галочка в настройках (модуль `meta`).
10. **Свои сайты** (экран «Статус» → «Свои сайты»): адрес + способ (zapret / DNS / через VPN; недоступные — серые с
   объяснением), «Проверить, открывается ли», список с «Убрать». `install.sh sites`.
11. **Подбор настроек zapret** (экран «Статус»): `install.sh tune`, ход по способам, «Вернуть как было» (`tune --undo`);
    там же «Способы для видео» — свой круг способов для серверов YouTube (`tune video on|off`).
12. **Обновление**: если на роутере switchback старше программы (событие `installed`), на экранах анализа и статуса —
   плашка «Обновить switchback на роутере» (`install.sh update`).
   На экране статуса — строка «Списки: версия N» (`install.sh lists`) и кнопка «Обновить списки» (`lists.go`):
   программа скачивает `lists/` с GitHub raw, при ошибке — с Codeberg, проверяет подпись Ed25519 файла
   `SHA256SUMS`, суммы, версию и каждую строку (без широких и домашних сетей), отправляет архив в
   `install.sh lists put` (прежние списки — в `lists.prev/`, затем `lists apply`: добавляет нужное и убирает
   с роутера то, что исчезло из списков, но только записи, которые ставил сам switchback). Если `apply`
   упал или проверки связи (как в `status`) стали хуже, роутер сам возвращает прежние (событие
   `lists_rollback`) и пишет в бот. Кнопка «Вернуть прежние» — `install.sh lists restore` (списки меняются
   местами, повторное нажатие возвращает новые).
   Пока в `listsPubKey` нет ключа, кнопка отвечает «Обновления списков ещё не включены». Подписание —
   `go run ./tools/lists-sign` (ключ вне репозитория).
13. **Подойдёт ли роутер** (в «Что нужно заранее» → «Другая / не знаю»): модель ищется в официальном списке
   устройств последнего стабильного OpenWrt (downloads.openwrt.org: `.versions.json`, `releases/V/.overview.json`);
   **помощник прошивки**: шаги, ссылки на выбор прошивки и страницу устройства, проверка скачанного файла по
   контрольным суммам (`targets/T/profiles.json`) и типу (factory / sysupgrade). Сама программа ничего не прошивает.

## Сборка

Нужны Go и Wails CLI (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`). Node.js не нужен.

```powershell
cd app
wails build -clean -trimpath   # -> build\bin\switchback.exe
```

`-trimpath` обязателен для раздачи: без него в программу попадают полные пути к исходникам, а с ними — имя
пользователя Windows того, кто собирал.

Перед сборкой Wails сам запускает `tools/bundle`. Он упаковывает `install.sh`, `lib/` и `platforms/` в
`installer/switchback.tar.gz` (этот файл не хранится в git), а оттуда установщик встраивается в .exe.
Для `go test` или `go build` без Wails сначала выполните `go generate ./...`.

## Проверка без роутера

```powershell
go test ./...                 # поддельный SSH-сервер + имитация Keenetic из tests/
go run ./tools/fakerouter     # поддельный Keenetic на 127.0.0.1:2222, пользователь root, пароль secret
wails dev                     # окно в режиме разработки; его же можно открыть в браузере на http://localhost:34115
```

Для этого нужен POSIX sh: на Windows его даёт Git for Windows.

## Устройство

- `main.go` — окно.
- `app.go` — методы, которые вызывает окно: `Connect`, `Analyze`, `Disconnect`, `ForgetKey`.
- `install.go` — `Install`, `Uninstall`, `CheckBot`, `SaveBackup`: запуск установщика отдельно от сессии, чтение его журнала.
- `keenetic.go` — `KeeneticCheck`, `InstallEntware` (веб-интерфейс Keenetic до установки Entware).
- `dns.go` — `DNSPresets`, `CheckDNS` (DoT/DoH-запрос из Go, открытие сайта через выданный адрес).
- `ntfy.go` — `NewNtfyChannel`, `TestNtfy`.
- `upnp.go` — `DetectRouter`; `firmware.go` — `FirmwareHint`.
- `extras.go` — `Sites`, `SiteAdd`, `SiteDel`, `SiteCheck`, `Update`, `Tune`.
- `lists.go` — `ListsVersion`, `UpdateLists`: скачивание, проверка и отправка списков.
- `wireguard.go` — `ImportWireGuard`; `openwrt.go` — `CheckModel`, `CheckImage` (данные OpenWrt, контрольные суммы).
- `router.go` — SSH: подключение, проверка ключа роутера, загрузка установщика, запуск команд с построчным выводом.
  Строки `@@sb` уходят в окно событием `sb:event`, остальные — событием `sb:log`.
- `frontend/dist/index.html` — интерфейс.
- `internal/fakessh` — поддельный SSH-сервер (только для тестов и разработки).
- `tools/bundle`, `tools/fakerouter` — вспомогательные программы.
