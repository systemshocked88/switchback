# 6. Еженедельный бэкап

Каждое воскресенье ночью на флешку сохраняются:
- `router-ДАТА.txt`: все настройки роутера (тот же текст, что в бэкапе из веб-интерфейса);
- `entware-ДАТА.tar.gz`: папка `/opt/etc` (zapret, списки, сторож) **без токена бота**.

Хранятся 8 последних (~2 месяца). Если бэкап не получился, бот пришлёт `BACKUP FAILED` (если настроен шаг 5).

В бэкапе настроек роутера есть хэш пароля администратора и зашифрованный пароль Wi-Fi, как и в бэкапе из
веб-интерфейса. Он лежит на флешке внутри роутера, доступ только у root. Никуда его не выкладывайте.

## Установка

Нужен `cron` (шаг 5.1).
```
mkdir -p /opt/etc/cron.weekly
cat > /opt/etc/cron.weekly/backup << 'EOF'
...сюда вставить scripts/backup.sh...
EOF
chmod +x /opt/etc/cron.weekly/backup
```

Пробный запуск и проверка, что токена в архиве нет (последнее число должно быть `0`):
```
/opt/etc/cron.weekly/backup; ls -l /opt/backup; tar tzf /opt/backup/entware-*.tar.gz | grep -c bot.conf
```

## Достать бэкап на ПК

```
ssh root@192.168.1.1 cat /opt/backup/router-2026-01-04.txt > router-backup.txt
```
Восстановить: http://192.168.1.1 → Общие настройки → Конфигурация → startup-config → загрузить файл.
