# 1. Entware: пакеты на флешке

Entware — это набор Linux-программ, который ставится на USB-флешку роутера. Через него ставится zapret
и работают скрипты.

Официальная инструкция Keenetic: https://help.keenetic.com/hc/ru/articles/360021214160

## 1.1. Компоненты Keenetic

**Общие настройки → Изменить набор компонентов**, включите:
- **Поддержка открытых пакетов** (OPKG);
- **Модули ядра подсистемы Netfilter** (нужны zapret);
- **Протокол IPv6** (обычно уже включён);
- если планируете Telegram через VPN: **WireGuard VPN**.

Роутер обновится и перезагрузится.

## 1.2. Флешка

1. Отформатируйте флешку в **ext4**. На Windows: бесплатный AOMEI Partition Assistant (скачивайте с официального
   сайта) или любой Linux. Метку тома можно задать, например, `ENTWARE`.
2. Узнайте архитектуру роутера: в описании вашей модели на help.keenetic.com или по процессору. Обычно это
   `mipsel` (старые/недорогие: Extra, Air, City...), `mips` или `aarch64` (новые: Giga KN-1012, Hopper...).
3. Скачайте установщик **только с официального сайта Entware**: https://bin.entware.net/ →
   `mipselsf-k3.4/installer/mipsel-installer.tar.gz` (или `aarch64-k3.10/...`, `mipssf-k3.4/...` под вашу архитектуру).
4. На флешке создайте папку `install` и положите туда этот файл **не распаковывая**.
5. Вставьте флешку в роутер.

## 1.3. Установка

**Приложения → OPKG** → выберите флешку → Сохранить. Установка идёт сама 2–5 минут, ход виден в
**Диагностика → Журнал**. В конце будет сообщение, что установка завершена.

## 1.4. Первый вход и пароль

В PowerShell на компьютере:
```
ssh root@192.168.1.1
```
Стандартный пароль: `keenetic`. **Сразу смените его:**
```
passwd
```

## 1.5. Источники пакетов по https

По умолчанию пакеты скачиваются по http. Переведите на https:
```
cp /opt/etc/opkg.conf /opt/etc/opkg.conf.orig
sed -i 's#http://bin.entware.net#https://bin.entware.net#' /opt/etc/opkg.conf
opkg update
```
Если `opkg update` ругается на сертификаты: `opkg install ca-bundle wget-ssl` (через старый http-конфиг), потом
снова переключите на https.
