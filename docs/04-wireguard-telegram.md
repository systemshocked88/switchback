# 4. WireGuard только для Telegram

Telegram плохо обходится через zapret, а пускать через VPN весь интернет не хочется: медленнее, и банки и госуслуги
не любят зарубежные адреса. Решение: туннель WireGuard, через который идут **только адреса Telegram**.

## 4.1. Конфиг

Нужен файл `.conf` WireGuard от любого VPN-сервиса. Внутри строки `[Interface]` (ваш `PrivateKey`, `Address`)
и `[Peer]` (`PublicKey`, `Endpoint` — адрес сервера). **`PrivateKey` никому не показывайте.**

## 4.2. Импорт

1. Компонент **WireGuard VPN** должен быть установлен (шаг 1.1).
2. **Интернет → Другие подключения → WireGuard → Загрузить из файла** → выберите `.conf`.
3. В настройках подключения:
   - **снимите** галочку «Использовать для выхода в интернет»: иначе через VPN пойдёт всё;
   - **удалите DNS-серверы**, если они пришли из конфига (часто `1.1.1.1`). Иначе DNS всего дома может уйти в туннель;
   - устройство в политики доступа **не** добавляйте.
4. Включите подключение. В командной строке:
   ```
   show interface Wireguard0
   ```
   Должно быть `state: up`, `online: true`, а `last-handshake` — небольшое число секунд.

Имя интерфейса может быть `Wireguard1` и т.д., если их несколько. Подставляйте своё.

## 4.3. Маршруты Telegram

Официальный список адресов Telegram: https://core.telegram.org/resources/cidr.txt (берите IPv4-строки).
На момент написания он такой. В командной строке Keenetic (http://192.168.1.1/a), по одной строке:
```
ip route 91.108.56.0 255.255.252.0 Wireguard0 auto
ip route 91.108.4.0 255.255.252.0 Wireguard0 auto
ip route 91.108.8.0 255.255.252.0 Wireguard0 auto
ip route 91.108.16.0 255.255.252.0 Wireguard0 auto
ip route 91.108.12.0 255.255.252.0 Wireguard0 auto
ip route 149.154.160.0 255.255.240.0 Wireguard0 auto
ip route 91.105.192.0 255.255.254.0 Wireguard0 auto
ip route 91.108.20.0 255.255.252.0 Wireguard0 auto
ip route 185.76.151.0 255.255.255.0 Wireguard0 auto
system configuration save
```
`auto` значит: если туннель упадёт, маршрут временно отключится, и Telegram пойдёт напрямую, а не пропадёт совсем.

Перевод маски: `/22` = `255.255.252.0`, `/20` = `255.255.240.0`, `/23` = `255.255.254.0`, `/24` = `255.255.255.0`.

## 4.4. Проверка

Откройте Telegram на телефоне: чаты и картинки должны грузиться. Счётчик `rxbytes` в `show interface Wireguard0`
должен расти.

Если на ПК в Telegram Desktop включён прокси (например, от Zapret GUI), его можно выключить: роутер уже везёт
Telegram через туннель для всех устройств.

## Так же можно и для других сервисов

Тот же приём работает для любого сервиса со своими адресами: найдите его сети (например, по номеру AS на
https://stat.ripe.net) и добавьте маршруты. Но много мелких сетей лучше склеить (в Python:
`ipaddress.collapse_addresses`).
