# 7. Если что-то сломалось

## Сначала

1. Перезагрузите роутер: всё настроенное поднимается само за 3–4 минуты.
2. Подождите 5 минут. Если стоит сторож, он напишет `BACK`, когда починится.

## По симптомам

| Симптом | Что проверить |
|---|---|
| Не работает YouTube / Discord / Instagram | `/opt/etc/init.d/S51nfqws2 status` → не `running`, тогда `restart`. Режим `list`? Домен есть в `user.list`? |
| После включения zapret сломалось что-то ещё | `/opt/etc/init.d/S51nfqws2 stop` и проверить. Не обрабатывает ли zapret ПК со своим обходом? (исключить ПК) |
| Не грузится Telegram | `show interface Wireguard0`: `state: up`? `last-handshake` < ~180 с? Маршруты на месте? Подписка VPN жива? |
| ChatGPT / Claude «недоступно в вашей стране» | DNS по доменам на месте? Не протекает ли через HTTPS-записи (`nslookup -q=TYPE65 ...`)? Жив ли DNS-сервис? |
| Сайт работает, приложение через раз | Мёртвые узлы прокси или QUIC: закрепить узел (`ip host`) и запретить UDP 443 к нему |
| На ПК всё работает, на телефоне нет | Телефон берёт DNS не у роутера (Private Relay, свой DNS-профиль, «Частный адрес»)? |
| Не работает вообще ничего | Обычный сайт открывается? Нет — проблема у провайдера. Да — выключить zapret и проверить |

## Откат

| Что | Как |
|---|---|
| zapret | `/opt/etc/init.d/S51nfqws2 stop`; исходный конфиг в `nfqws2.conf.orig` |
| Маршрут | `no ip route <сеть> <маска> Wireguard0` |
| Закреплённый адрес | `no ip host <домен>` |
| Сторож / бэкап | `rm /opt/etc/cron.5mins/watchdog` / `rm /opt/etc/cron.weekly/backup` |
| Всё | загрузить сохранённый `startup-config` (шаг 0) |

После изменений в командной строке Keenetic: `system configuration save`.
