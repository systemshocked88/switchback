# switchback 0.7.6 — что нового

## Что нового

- **Резерв для нейросетей: Claude и ChatGPT переключаются сами.** Если DNS-сервис для них перестал работать (так
  было 18.11: Claude не открывался дома с утра до вечера), роутер сам ищет другой путь, по порядку: DNS-сервис →
  Zapret DNS → запасные прокси → VPN через активный туннель. Путь берётся только после проверки, что через него сайт
  открывается. Раз в час роутер пробует вернуться на путь получше. О переключении, о том, что не помог ни один путь,
  и о возвращении он сразу пишет в бот и в ntfy.
  - **Вручную — в боте:** команда `/ai` или кнопка «Claude» в меню, дальше кнопки «Claude через VPN», «Следующий
    путь», «Авто» (снова сам) и «Статус». Выбранный вручную путь держится сутки, потом роутер снова выбирает сам.
    Кнопки переключают сразу и Claude, и ChatGPT.
  - **С роутера:** `sh install.sh ai status`, `ai via vpn` (или `zdns`, `proxy`, `dns`; можно добавить число часов),
    `ai next`, `ai auto`; включить и выключить — `ai on` / `ai off` (выключение возвращает всё как было).
  - **В программе:** галочка «Резерв для нейросетей» рядом с DNS-сервисами (включена по умолчанию); на Keenetic
    можно выбрать сервис «Zapret DNS» — он тоже работает через резерв.
  - **Проверено вживую** на Keenetic 19.11: все четыре пути и кнопки в боте. По итогам проверки исправлено: путь
    через VPN, чтение ответов Zapret DNS на роутере, `/ai` теперь отвечает коротко и только про резерв, а запасной
    прокси в сообщениях бота назван прокси, а не «узлом».
- **Видео в приложении YouTube на телефоне.** Новый способ обхода для QUIC (так приложение YouTube качает видео)
  ставится по умолчанию при установке и обновлении. На живом роутере дальние серверы видео стали отдавать мегабайты
  вместо нескольких килобайт. Ваш собственный способ, если вы меняли его вручную, не трогается.
- **Если видео на телефоне всё равно тормозит:** кнопка «Видео на телефоне тормозит» в «Что-то не работает» или
  команда `/quic` в боте. С роутера — `sh install.sh tune quic status` (сколько пришло от каждого сервера видео),
  `tune quic next` (попробовать следующий из 4 способов), `tune quic undo` (вернуть как было до первой пробы).
- **У каждого сервера видео свой способ.** Круг способов для серверов видео YouTube стал длиннее — 7 штук — и теперь
  считается по каждому серверу отдельно: перестал работать способ у одного сервера — меняется только у него.
  Подбор zapret (`tune`, «Подобрать zapret») пробует 12 способов, пять новых взяты из большой проверки на домашнем
  компьютере. Подбор теперь идёт 4–11 минут.
- **«Спасение видео» убирает лишнее само.** Серверы видео, которые раньше пришлось увести в туннель, раз в час
  проверяются напрямую. Отвечают напрямую дважды подряд — маршрут через туннель снимается: на живом роутере 16 из 48
  таких серверов снова работали напрямую и только тормозили телефон через туннель.
- **«Доктор» сайта.** Пришлите боту `/diag адрес` (или просто ссылку) — он по шагам проверит интернет, сам сайт,
  его адрес, zapret и туннель и скажет простыми словами, почему не открывается и что поможет. С роутера —
  `sh install.sh sites doctor адрес`.
- **Панель на роутере для телефонов** (по умолчанию выключена). Одна страница: работают ли YouTube, Telegram,
  Instagram, ChatGPT, Claude и свои сайты и каким путём идут; кнопка «Переключить на следующий» туннель; проверка
  «Не открывается сайт?» с кнопкой «Исправить». Включить — `sh install.sh panel on`, вход по секретной ссылке
  (`panel link`, новая ссылка — `panel token`), пароль роутера не нужен. Открывается только из домашней сети.
  Выключить — `panel off`.
- **Обновляемые списки адресов и способов.** Адреса Telegram, Instagram, сайтов для zapret, ChatGPT, Claude и
  способы zapret теперь лежат в отдельных списках. Кнопка «Обновить списки» в программе скачивает свежие списки
  с GitHub (или с запасной копии на Codeberg), проверяет подпись и только тогда отправляет на роутер. Если после
  обновления что-то стало хуже — роутер сам возвращает прежние списки и пишет об этом в бот. Вернуть вручную —
  кнопка «Вернуть прежние» (или `sh install.sh lists restore`). Адреса, выпавшие из новых списков, с роутера
  убираются; ваши свои сайты и ручные записи остаются.
- **Запасная копия на Codeberg:** https://codeberg.org/systemshocked/switchback — обновляется с каждым выпуском.
  Если GitHub не отвечает, программа проверяет обновления там. Файлы выпусков (exe) — только на GitHub.
- **OpenWrt: 11 исправлений** по итогам проверки на OpenWrt 24.10 и 25.12 в виртуальной машине. Главное:
  «Откатить всё» теперь возвращает роутер как был (убирает добавленные пакеты и источник пакетов, оставляет то, что
  стояло раньше); DNS через https-dns-proxy больше не забирает весь DNS роутера — шифрованно идут только наши сайты;
  установка ждёт, пока zapret запустится, вместо ложного «zapret не запустился»; сторож без бота не оставляет лишних
  заданий; работает на BusyBox без `od`.
- **Туннели из архивов проверены вживую.** `wg-batch` / «Проверить и добавить» из 0.7.5 проверены на живом Keenetic
  17.11: архивы приняты, 5 рабочих туннелей встали запасными. Пока только для Keenetic; отчёты с другими подписками
  по-прежнему пригодятся.
- **Формы отчётов на GitHub:** четыре короткие формы — «Не открывается сайт / YouTube», «Не ставится / ошибка при
  установке», «Telegram / туннели WireGuard», «Проверено на моём роутере»; вопросы — в «Обсуждения»:
  https://github.com/systemshocked88/switchback/issues/new/choose

## Как обновиться

- **Через программу:** скачайте новый `switchback.exe`, подключитесь к роутеру — на экране анализа или статуса появится
  плашка «Обновить switchback на роутере». Настройки не меняются; новый способ для QUIC ставится сам (если вы не
  меняли его вручную).
- **Вручную:** `sh install.sh update` из папки новой версии на роутере.
- Панель сама не включается: `sh install.sh panel on`, если она нужна.
- Резерв для нейросетей при обновлении тоже сам не включается: `sh install.sh ai on` или галочка «Резерв для
  нейросетей» при установке DNS в программе.
- Проверьте скачанный файл: число из `Get-FileHash switchback.exe` должно совпасть с `SHA256.txt` на странице выпуска.

  ещё нет. Если после «Обновить списки» что-то сломалось и само не вернулось — «Вернуть прежние» и сообщите в Issues.

  OpenWrt проверен только тестами.
