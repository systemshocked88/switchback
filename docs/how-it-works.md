# Как это работает: что за что отвечает

Четыре независимых части. Каждую можно ставить отдельно (профили `zapret`, `dns`, `vpn`) или вместе
(`full`). Они не мешают друг другу, потому что работают с **разным трафиком** и на **разных уровнях**.

## Путь трафика

```
Телефон / ТВ / ПК ──► роутер ──┬─► YouTube, Discord, Instagram ──► [zapret] ──► провайдер ──► сайт
                               │      (напрямую, но первые пакеты «замаскированы»)
                               │
                               ├─► chatgpt.com, claude.ai ──► [DNS по сервисам] отдаёт адрес прокси
                               │      ──► провайдер ──► прокси за границей ──► сервис
                               │
                               ├─► адреса Telegram ──► [маршрут] ──► туннель WireGuard ──► VPN-сервер ──► Telegram
                               │
                               └─► всё остальное ──► провайдер ──► сайт (как раньше)
```

## Части по отдельности

| Часть | Что делает | Где работает | От чего зависит | Если сломается |
|---|---|---|---|---|
| **zapret** | Изменяет первые пакеты соединения так, чтобы система блокировки провайдера (DPI) не узнала сайт. Трафик идёт **напрямую**, без VPN, поэтому скорость не падает | только сайты из списка (`user.list` и встроенные списки) | ни от чего | не откроются YouTube/Discord/Instagram; остальное работает |
| **DNS по сервисам** | Для доменов ChatGPT и Claude роутер спрашивает не провайдера, а DNS-сервер сервиса-прокси (по зашифрованному DoT). Тот отдаёт адрес своего прокси за границей | только перечисленные домены (до 8 записей) | работоспособность DNS-сервиса | ChatGPT/Claude скажут «недоступно в вашей стране»; остальное работает |
| **VPN для Telegram** | Маршруты: «трафик на адреса Telegram — в туннель WireGuard». Остальное идёт мимо VPN | только официальные сети Telegram | VPN-подписка (сервер, ключ) | Telegram пойдёт напрямую (маршруты с `auto` отключаются при падении туннеля) |
| **Сторож + бэкап** | Раз в 5 минут проверяет части выше и пишет в Telegram при сбое и восстановлении. Раз в неделю сохраняет настройки | — | бот в Telegram, `curl`, `cron` | перестанут приходить уведомления; сама сеть работает |

## Как части связаны

- **zapret и DNS независимы.** zapret не трогает ChatGPT/Claude: они не в его списке, а DNS не трогает YouTube.
- **Сторож пишет через Telegram, а Telegram идёт через VPN.** Если упал VPN, сообщить сразу нельзя.
  Поэтому сторож запоминает время сбоя и, когда VPN вернётся, присылает `WAS DOWN: … (~N мин)`.
- **ПК со своим обходом** (zapret для Windows, GoodbyeDPI) надо исключить из zapret на роутере.
  Два обхода на одном трафике ломают соединения: это главный подводный камень.
- **DNS-обход и VPN не пересекаются:** DNS-обход не использует туннель, VPN не меняет DNS.

## Чего установщик НЕ делает

- Не настраивает сам WireGuard: ключи и сервер ваши, их вы импортируете мышкой (docs/04).
- Не выбирает за вас DNS-сервис-прокси: адреса меняются, берите актуальные на его сайте.
- Не трогает Wi-Fi, пароли, прошивку и порты.
- Не подбирает стратегии zapret под провайдера: берётся стандартная настройка пакета. Если YouTube
  не открылся, смотрите README пакета zapret для вашей прошивки.

## Подводные камни, на которых мы спотыкались

1. **Режим `auto` у zapret** сам решает, что «обходить», и иногда ломает работающие сайты. Установщик ставит `list`.
2. **Утечка через HTTPS-записи:** некоторые DNS-прокси подменяют обычный адрес, но в записи HTTPS (тип 65)
   оставляют настоящий; iPhone идёт напрямую. Проверка: docs/02-dns.md#проверка-на-утечку.
3. **QUIC (HTTP/3 по UDP 443):** приложения ходят по нему. Если сайт в браузере работает, а приложение через раз,
   закрепите адрес и запретите UDP 443 к нему (docs/02-dns.md).
   Но не запрещайте QUIC для YouTube/Instagram «на всякий»: у некоторых провайдеров zapret пробивает их только по QUIC.
4. **Один DoT-сервер на весь дом:** если он упадёт, пропадёт DNS у всех. Поэтому записи привязаны к доменам.
