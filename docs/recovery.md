# Если что-то сломалось: восстановление

Установщик перед любыми изменениями сохраняет **снимок** настроек, а при сбое посреди установки сам
откатывает то, что успел сделать. Ниже — что делать, если этого не хватило.

## Где снимки

Хранятся 5 последних, в папке `ДАТА-ВРЕМЯ`:

| Прошивка | Папка | Файлы |
|---|---|---|
| Keenetic / Netcraze | `/opt/etc/switchback/backups/` | `router-config.txt` — все настройки роутера (как «Конфигурация → startup-config»); `entware-etc.tar.gz` — zapret, списки, сторож (без токена бота); `packages.txt` |
| OpenWrt | `/etc/switchback/backups/` | `openwrt-backup.tar.gz` — все настройки (как «System → Backup»); `packages.txt` |

В снимке есть хэш пароля администратора и пароль Wi-Fi: никуда его не выкладывайте.

**Скачайте снимок на компьютер сразу после установки** (подставьте дату):
- Keenetic (PowerShell на ПК):
  ```
  ssh root@192.168.1.1 cat /opt/etc/switchback/backups/20260101-120000/router-config.txt > router-config.txt
  ```
- OpenWrt (командная строка ПК; архив двоичный, поэтому `scp`, а не `cat`):
  ```
  scp -O root@192.168.1.1:/etc/switchback/backups/20260101-120000/openwrt-backup.tar.gz .
  ```
  Или проще: веб-интерфейс → System → Backup / Flash Firmware → Generate archive.

Снимок понадобится, если роутер придётся сбрасывать.

## Ступени: от простого к сложному

### 1. Сломался один сервис, остальное работает
Смотрите [07-troubleshooting.md](07-troubleshooting.md) по симптому. Часто хватает перезагрузки роутера.

### 2. Хочу убрать всё, что поставил установщик
```
sh install.sh uninstall
```
Покажет список изменений, спросит подтверждение и отменит их в обратном порядке. Ваши ручные настройки
не трогает. Есть `--dry-run`, чтобы сначала посмотреть.

### 3. Пропал интернет, но веб-интерфейс роутера открывается
- **Keenetic / Netcraze:** http://192.168.1.1 → Общие настройки → Конфигурация → `startup-config` →
  загрузить сохранённый `router-config.txt`. Роутер перезагрузится с настройками до установки.
  Быстро выключить zapret (если подозрение на него): `/opt/etc/init.d/S51nfqws2 stop`.
- **OpenWrt:** http://192.168.1.1 → System → Backup / Flash Firmware → Restore backup → загрузить
  `openwrt-backup.tar.gz`. Или по SSH: `sysupgrade -r /etc/switchback/backups/ДАТА/openwrt-backup.tar.gz`.
  Быстро выключить zapret: `service nfqws2-keenetic stop`.

### 4. Роутер не загружается или недоступен
- **Keenetic / Netcraze:**
  1. Выньте USB-флешку и перезагрузите роутер: без флешки Entware, zapret и сторож не запустятся,
     и роутер стартует как обычный.
  2. Не помогло — **сброс к заводским**: зажмите кнопку Reset на ~10 секунд, подключитесь по Wi-Fi
     с заводским паролем с наклейки.
  3. Загрузите сохранённый `router-config.txt` (ступень 3). Флешку можно вставить обратно.
- **OpenWrt:**
  1. **Безопасный режим (failsafe):** при загрузке, когда замигает индикатор, несколько раз нажмите Reset.
     Подключитесь кабелем, адрес 192.168.1.1, `ssh root@192.168.1.1` без пароля, затем `mount_root`
     и верните настройки: `firstboot && reboot` (сброс) или `sysupgrade -r` с архивом.
     Точная кнопка и индикатор зависят от модели: смотрите страницу модели на openwrt.org.
  2. **Сброс к заводским:** зажмите Reset ~10 секунд. Затем загрузите `openwrt-backup.tar.gz` (ступень 3).

## Что откатывается автоматически

Если установка оборвалась (ошибка, пропал интернет, Ctrl+C), установщик сам отменяет изменения
**этого запуска** в обратном порядке: DNS-записи, маршруты, правки zapret и списков, файлы сторожа,
на OpenWrt — изменённые настройки (ускорение, https-dns-proxy) и строки расписания.
Установленные пакеты (zapret, https-dns-proxy, curl, cron) оставляет: они безвредны, их можно удалить
через `uninstall`.
Изменения прошлых успешных запусков не трогает.
